# WhiteRabbitNeo как агент на вашем ноутбуке

Цель: модель думает на арендованной GPU (под RunPod), но **все действия** —
чтение файлов, запуск команд, выход в интернет — происходят на вашем ноутбуке.
Сервер это только «мозг», руки — локальные. Реализуется через Claude Code,
направленный на вашу модель.

## Как это устроено

```
Ваш ноутбук                                  Под RunPod (H100)
┌─────────────────────────────┐             ┌──────────────────────┐
│ Claude Code                 │             │ llama-server         │
│  • читает ваши файлы        │  SSH-туннель │  • WhiteRabbitNeo 70B│
│  • запускает команды        │─────────────▶│  • только инференс   │
│  • ходит в интернет С НОУТА │  (шифрован)  │  • слушает 127.0.0.1 │
│  • НЕ шлёт данные напрямую  │             │  • НЕ трогает ваши   │
│    провайдеру               │             │    файлы и сеть      │
└─────────────────────────────┘             └──────────────────────┘
```

Инструменты и сеть — на вашей стороне. На под уходит только текст запроса к
модели, и только через зашифрованный SSH-туннель, минуя HTTP-прокси RunPod.

## Порядок запуска

### Шаг 1. Перезапустить сервер с поддержкой инструментов (в SSH-сессии на поде)

Текущий сервер запущен без флага `--jinja`, а он обязателен для tool calling.
В том окне, где вы уже залогинены на под по SSH, выполните
`restart-server-on-pod.sh` (скопируйте его туда или вставьте команды вручную).
Дождитесь в логе строки `server is listening`.

### Шаг 2. Открыть туннель (окно 1 на ноутбуке)

Отредактируйте `tunnel.ps1` — впишите путь к приватному ключу, IP и порт пода,
затем:

```powershell
powershell -ExecutionPolicy Bypass -File .\tunnel.ps1
```

Оставьте окно открытым.

### Шаг 3. Запустить агента (окно 2 на ноутбуке)

Установите Claude Code (https://claude.com/claude-code). Задайте ключ модели
в переменной окружения (тот самый `--api-key`, что задан на сервере), затем
запустите:

```powershell
$env:WHITERABBIT_KEY = "<ваш-ключ-модели>"
powershell -ExecutionPolicy Bypass -File .\run-agent.ps1
```

Ключ модели намеренно не зашит в скрипт — он не должен попадать в репозиторий.

Скрипт направит Claude Code на вашу модель через туннель и проверит связь
перед запуском. Дальше Claude Code работает как обычно, но «мозгом» служит
WhiteRabbitNeo, а не облако Anthropic.

## Что важно понимать

- **Приватность действий.** Инструменты и сетевые запросы исполняет Claude Code
  на вашем ноутбуке. Провайдер GPU видит только зашифрованный поток к модели.
- **Это не то же самое, что аппаратная приватность.** Оператор дата-центра
  теоретически всё ещё имеет доступ к памяти виртуалки пода (нет TEE). Доказуемую
  защиту даёт только confidential computing — см. `infra/private-llm/` (Phala).
- **Качество агента.** 70B-модель в 4-битном кванте заметно слабее облачных
  моделей в сложных агентных задачах (многошаговые планы, аккуратные tool-calls).
  Для простых задач подойдёт, для сложных возможны сбои в вызовах инструментов.
- **Ключи.** Приватный SSH-ключ и ключ модели остаются у вас. API-ключ RunPod,
  засвеченный в переписке, стоит перевыпустить в настройках RunPod.
