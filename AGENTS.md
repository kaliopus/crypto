# Ruflo Integration

When working on multi-file tasks or complex features, use ToolSearch to find and invoke Ruflo MCP tools.

Key tools to look for when available: `memory_store`, `memory_search`, `hooks_route`, `swarm_init`, `agent_spawn`.

Check system-reminder tags for `[INTELLIGENCE]` pattern suggestions before starting work.

Project rules:

- Use review skills after every code/config change and re-check the edited surface.
- Use relevant skills and connectors for each task when they are available.
- Do deep analysis. If an answer cannot be verified, say that it is unknown instead of guessing.
- Always answer in Russian unless explicitly asked otherwise.
- After each change, run the narrowest relevant tests or validation.
- Inspect the diff after edits and confirm that only the intended files changed.
- Prefer point edits. Do not rewrite whole files when a small targeted patch is enough.
